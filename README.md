# Bioacoustic Audio Analysis

This project extracts acoustic features from environmental recordings and trains a machine learning model to classify ecosystem sounds.

## Dataset

The dataset is large and is not included in this repository.

Download the feature dataset here:

https://drive.google.com/file/d/1TeYVBK-WO2hGI0_YyedyYlk3hKHy2ow-/view?usp=drive_link

After downloading, place the file in:

features/
    features_all.csv
